# 使用指南

本页介绍 SPlayer for Android Next 的基本使用。安装包请见 [下载](/download)。

## 首次启动

首次启动会进入引导页，按需授予以下权限：

| 权限                          | 用途                                   |
| ----------------------------- | -------------------------------------- |
| **通知**                      | 前台服务与 MediaStyle 媒体通知、后台保活 |
| **显示在其他应用上层**        | 灵动岛悬浮歌词等悬浮窗能力             |
| **SAF 目录授权**              | 本地音乐库、本地歌词、下载目录         |

应用升级（versionCode 变动）时会自动清理 WebView 资源缓存，首次进入稍慢属正常现象。

## 播放音乐

- **搜索播放**：在搜索页输入歌曲 / 歌手 / 专辑，点击即可播放或加入播放列表；
- **播放队列**：支持顺序、随机、单曲循环等模式；
- **音质与音效**：设置中可选择音质档位（Hi-Res / Lossless / HQ / SQ / LQ），并开启渐入渐出、音量均衡、均衡器等音效；
- **全屏播放器**：移动端全屏播放页采用单层 Grid 重叠布局与 FLIP 过渡，封面与文字 60fps 平滑切换；横屏时进入沉浸式模式，同时隐藏状态栏与手势导航条。

播放由原生层统一驱动：ExoPlayer、MediaSession 与预载管理器运行在专属 `SPlayerPlayback` 线程上，应用切到后台时频谱与进度推送会自动静默以节省功耗。

## 本地音乐

1. 在 **音乐库** 页面或 **设置 → 本地与缓存** 中，通过系统文档选择器授权要扫描的目录；
2. 原生扫描器结合 SQLite 建立索引，完成后即可按歌曲、专辑、歌手浏览；
3. 标签与封面由 `jaudiotagger` 读取；重新扫描可感知新增与变更。

## 流媒体

接入 Subsonic / Navidrome / Jellyfin / Emby 等自建服务器，详见 [流媒体服务](/streaming)。

## 歌词

支持 **LRC / QRC / YRC / KRC / TTML / lys / ass / srt** 多种格式，提供逐字高亮、翻译与音译。在线歌词按 **设置 → 歌词设置** 中的来源偏好、音源排序与格式偏好依次匹配；TTML 优先级最高，且仅在来源偏好为自动、网络 TTML 更优时才会静默升级，你显式指定的来源不会被篡改。

### 在线 TTML 歌词（AMLL TTML DB）

[AMLL TTML DB](https://github.com/amll-dev/amll-ttml-db) 是社区维护的 TTML 歌词数据库，提供制作精良的逐字歌词与翻译、音译：

- 在 **设置 → 歌词设置** 中开启 **启用在线 TTML 歌词**；
- 可配置 **AMLL TTML DB 地址**，地址是含 `%p`（平台）与 `%s`（歌曲 ID）两个占位符的模板，填错会导致获取失败。

### 本地 TTML 歌词库

- 开启 **启用本地 TTML 歌词库** 并选择存放 `.ttml` 的目录；
- 应用按歌曲元信息（曲名 / 艺术家等）在库中查找；
- **命中本地歌词时优先于在线歌词**，方便用你自己的校对版本覆盖在线结果。

### 原生歌词层

全屏播放页的歌词由 Kotlin 原生 Canvas 层渲染（叠加在 WebView 之上），支持逐行模糊与退场浮动衰减；模糊位图按 0.5x 降采样并受内存预算约束，兼顾观感与功耗。竖屏快捷操作弹窗会自动向原生层注册触摸避让区，避免误触歌词定位。

## 插件

内置插件系统可通过脚本扩展音源与控制能力，安装与管理见 [插件使用](/plugins-usage)，自行编写见 [插件开发](/plugins/)。Android 端的插件运行时由内嵌 Node.js Mobile 提供。

## 下载管理

在 **设置 → 下载配置** 中配置下载目录与音质等选项，下载任务在 **下载** 页面统一管理。

## 局域网分享与跨端同步

**设置 → 局域网分享** 开启后，设备上的原生服务（端口 `13962`）会在局域网内提供：

- 跨端曲库与播放列表同步；
- 网页端播放控制；
- 受限的外部 API 访问，详见 [外部 API](/api)。

## 通知与后台

播放时应用通过前台服务 + MediaStyle 通知保持后台存活，通知与系统媒体面板提供播放 / 暂停、上一首 / 下一首等控制；拔掉耳机等音频焦点事件由原生层统一处理。

## 设置一览

设置共以下分组，部分分组中的个别项标注「仅在桌面端可用」，在 Android 版中不显示：

| 分组         | 内容概要                                     |
| ------------ | -------------------------------------------- |
| 常规设置     | 语言、启动行为、备份与恢复、重置             |
| 播放设置     | 音质档位、渐入渐出、音量均衡、均衡器、变速   |
| 歌词设置     | 来源偏好、音源排序、格式偏好、AMLL / 本地 TTML、字体与样式 |
| 外部歌词     | 外部歌词窗口 / 字体的独立配置                |
| 外观设置     | 主题模式、取色、字体、界面元素               |
| 快捷键配置   | 播放控制快捷键（桌面端为主）                 |
| 网络与服务   | 流媒体服务器、代理、Last.fm 等第三方服务     |
| AI 集成      | AI 模型与相关能力配置                        |
| 媒体源配置   | 在线平台与音源相关配置                       |
| 下载配置     | 下载目录、音质、并发与附件                   |
| 本地与缓存   | 本地音乐目录、缓存上限与清理                 |
| 插件管理     | 插件安装 / 启用 / 设置 / 卸载与插件市场      |
| 局域网分享   | 局域网服务开关与同步选项                     |
| 其他设置     | 实验性与杂项选项                             |
| 关于软件     | 版本信息、更新日志与鸣谢                     |

## 外部控制

Android 版通过局域网服务提供受限的外部 HTTP API，可供同网络下的其他程序或网页查询状态与控制播放，详见 [外部 API](/api)。桌面版的 WebSocket API 与 MCP 接口不在 Android 版提供。
