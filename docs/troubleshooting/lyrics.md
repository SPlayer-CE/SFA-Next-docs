# 歌词问题

## 在线歌词不显示 / 只有纯文本

- 逐字歌词依赖 QRC / YRC / TTML 等资源，部分歌曲本身没有逐字歌词，显示纯文本 LRC 属正常；
- 检查 **设置 → 歌词设置** 的来源偏好与音源排序是否把可用来源排后或禁用；
- 已渲染有效歌词时，后续来源尝试失败**不会清空**现有歌词——若完全空白，多为所有来源均失败。

## TTML 歌词获取失败

- **在线 TTML（AMLL TTML DB）**：地址是含 `%p`（平台）与 `%s`（歌曲 ID）占位符的模板，填错会导致获取失败，可恢复默认地址重试；
- TTML 自动升级仅在来源偏好为「自动」且网络 TTML 更优时触发，你显式指定的来源不会被静默篡改；
- **本地 TTML 歌词库**：确认目录已选择且内含 `.ttml` 文件；匹配按歌曲元信息（曲名 / 艺术家等）进行，命中时优先于在线歌词。

## 全屏歌词空白（横竖屏切换后）

原生歌词层在旋转重建时存在竞态：旧实例的清理若晚于新实例装载歌词，会把它清空。应用已用**所有权令牌**（`activeKotlinHostToken`）修复该问题；若仍复现：

1. 切换一次播放曲目或重进播放页恢复；
2. 记录复现步骤与设备型号后[提交 Issue](https://github.com/SPlayer-CE/SPlayer-for-Android-Next/issues)。

## 歌词模糊效果异常 / 掉帧

逐行模糊受内存预算约束（位图 LRU 上限为堆内存 1/8，0.5x 降采样）：

- 低内存设备上模糊档位会自动降低，属预期降级；
- 若出现明显掉帧，关闭歌词模糊相关选项可立即缓解。

## 弹窗点击穿透到歌词

原生歌词层叠加在 WebView 之上并默认吞噬触摸。竖屏快捷弹窗已自动注册触摸避让区；若某个弹窗仍被穿透，请附截图与复现步骤反馈。

## 本地歌词 / 字体不生效

- 本地歌词目录与字体导入在 **外部歌词** 相关设置中管理，确认已授权 SAF 目录；
- 字体文件需为系统可解析格式，导入后在歌词字体设置中选用。

## 翻译 / 音译不显示

确认歌词设置中翻译与音译开关已开启；部分歌曲源数据不含翻译或音译行，属正常。
